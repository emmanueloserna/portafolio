# Portafolio · Emmanuel Ortiz Serna

Escritorio con carpetas: Webs, Videos, Juegos y Presentaciones. Publicado con GitHub Pages en https://emmanueloserna.github.io/portafolio/

- `index.html`: todo el sitio (datos de proyectos en `CARPETAS`, arriba del script).
- `media/`: videos comprimidos (H.264, faststart) y su miniatura `.jpg`.
- `thumbs/`: capturas de las webs (WebP) y el sprite de Claudia.
- `webs/`: copias de Batman, Peter Parker y Orión para que corran aquí.

Para agregar un proyecto: copiar el video a `media/<id>.mp4` (o la captura a `thumbs/`) y añadir una línea en `CARPETAS`.
